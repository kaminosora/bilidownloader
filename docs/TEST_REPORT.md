## 1.0.1 新增功能验证

「打开所在文件夹」在网页最近任务和完整任务页均通过真实 UI → 扩展消息 → 任务下载 ID 查询验证。无界面浏览器测试仅替换最终 `chrome.downloads.show` 调用以记录目标 ID，不实际打开资源管理器；系统窗口的可见行为需在桌面 Chrome 使用时验收。后端模块测试覆盖任务归属限制、第一轨丢失后定位第二轨、未知任务、记录清除、未完成文件和原生调用失败；UI 验证错误提示跨轮询保留并可重试。此版本不新增权限。

API 行为依据 [Chrome downloads.show 文档](https://developer.chrome.com/docs/extensions/reference/api/downloads#method-show)。`search` 的文件存在状态有缓存，刚刚在外部删除/移动的文件可能不会立即反映。

## 测试内容

单元/模块测试覆盖 BV、av、分 P、ep、ss 解析，WBI 签名，DASH AVC/HEVC/AV1 轨与普通/杜比/FLAC 音轨归一化，旧式 `durl` / PGC `durls` 分组与实际画质发现，备源、限流、请求超时、取消、无权限、试看和加密标记。公布的画质名称不会直接变成可下载资源。

下载测试覆盖域名与文件名校验、512 MiB 预算逻辑、未知长度累计、HTTP 错误、HTML/JSON 响应、局部 HTTP 206 拒绝、完整性检查、备用源、逐块写盘、磁盘配额错误和取消。任务模块覆盖终态不可复活、排队上限、丢失后台、陈旧下载查询与多轨下载中一轨失败时取消其他轨。

浏览器测试真实加载 `dist` 并运行打包的 WASM，验证页面嵌入、实际画质选择、分 P、SPA 更新、MP4/MKV 合并及 M4A/MP3/WAV/FLAC 输出。共保存并独立解码 **15 个合成媒体输出**；合成输入为 1.2 秒 H.264 视频和 AAC 音频。还验证原始双轨 OPFS 下载及临时文件清理、准备和下载阶段取消、失败后重试、处理中后台重启，以及**第一份原始轨保存返回前终止后台后恢复两份文件且不重复保存**。任务存储中未发现媒体 URL。

实站测试访问 [BV13x41117TL](https://www.bilibili.com/video/BV13x41117TL)，时长 554 秒。匿名接口返回 480P/360P 的 AVC 与 AV1 资源及三档 AAC 音轨；测试选择响应中的最低码率视频/音轨。原始视频 **9,714,047 字节**、原始音轨 **4,651,485 字节**、合并 MP4 **14,674,581 字节**，均完成 Chrome 保存并通过原生 FFmpeg 全文件解码。这个结果只证明该公开视频在本次网络环境中的实际下载，不等于所有站点资源均可用。

## 证据与复现

- `test-results/browser-report.json`：受控浏览器报告；`panel.png` / `tasks.png`：测试页面截图；`artifacts/`：合成输出。
- `test-results/live-report.json`：匿名实站报告，只保留资源规格、文件大小和结果，不保存签名媒体地址。
- 按 README 的开发者命令重建与复现；`npm run test:live` 会访问真实网络并下载测试视频。
- `node scripts/package.mjs --check` 检查发行输入；`npm run package` 生成安装 ZIP、源码 ZIP 与 SHA-256，生成时逐文件校验 ZIP CRC。

## 未覆盖与限制

未使用用户登录态，因此 **VIP、付费、地区受限、4K/8K、HDR/杜比与 Hi-Res 实际媒体**仍需在用户有相应权限的正常 Chrome 会话验收。解析器支持这些轨的相关结构，不表示所有编码组合都已实站验证。

未实际下载超过 512 MiB 的大文件或填满磁盘；大文件路径通过逐块写入、超过预算的声明长度、取消与配额异常测试验证。OPFS 原始轨仍受磁盘空间与浏览器存储配额限制。声明最低 Chrome 116，但本次实际浏览器测试仅覆盖上述 Chrome 156 测试版。源站 API、CDN、防盗链或风控变化仍可能使某个资源不可用。

不实现 DRM 解密、权限扩展、直播下载或互动分支遍历。完整退出浏览器后的未完成任务需重新开始，不承诺断点续传。源码审查发现的保存恢复、兄弟任务取消、准备请求取消和异步竞态已修复，并由针对性测试或浏览器回归覆盖。
