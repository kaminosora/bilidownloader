# Bili 本地下载 v1.0.1

下载完成后，可直接在网页内最近任务或全部任务列表点击「打开所在文件夹」，在系统资源管理器中定位保存的文件。多轨任务会定位仍存在的已完成文件；记录已清除、文件已移走或尚未保存完成时显示提示。

本版本首次在 GitHub 发布完整工程。保留纯 Chrome 扩展方式：选择实际可用画质和编码，本地合并 MP4/MKV、下载原始轨、导出 M4A/MP3/WAV/FLAC，无需额外启动程序。

## 安装与更新

1. 下载并解压 `bili-local-downloader-1.0.1.zip`。
2. 打开 `chrome://extensions`，启用「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择解压后含 `manifest.json` 的文件夹。
4. 更新已有安装时替换原扩展目录内容，再点击「重新加载」，刷新 B 站播放页。

`bili-local-downloader-1.0.1-source.zip` 是源码包；`SHA256SUMS` 用于校验两个 ZIP。

## 验证与边界

- 94 项模块测试、18 项浏览器检查通过；受控测试真实运行打包的 FFmpeg WASM 并解码输出。
- 文件夹按钮已验证两处 UI、消息链路和目标下载 ID。自动化测试替换最终系统窗口调用，未验证资源管理器可见窗口。
- 合并/转码输入总量上限 512 MiB；较大文件可原始分轨保存，受磁盘空间与浏览器存储配额限制。
- 仅处理当前账号实际获得的未加密资源；不提供 DRM 解密或权限绕过。登录、VIP 和受限资源需在自己的正常浏览器会话验收。
